# fitness# 🚀 Python Health & Fitness Tracker

Welcome to my Python project repository! This is a command-line application designed to analyze daily physical activity, nutrition habits, and sleep patterns to provide personalized health feedback.

## 📌 Features
- **Running Analysis:** Evaluates daily running duration and encourages consistency.
- **Nutrition Check:** Checks dietary habits to guide healthier choices.
- **Sleep Quality Monitor:** Reviews sleep duration to recommend optimal rest.
- **Conditional Logic:** Built entirely using Python `if-elif-else` decision structures and user inputs (`input()`, `int()`).

## 🛠️ Technologies Used
- **Language:** Python 3.x
- **Environment:** Visual Studio Code (VS Code)
- **Version Control:** Git & GitHub

## 🚀 How to Run
1. Make sure Python is installed on your computer.
2. Clone this repository or download the `main.py` file.
3. Open your terminal and run the script:
   ```bash
   python main.py
